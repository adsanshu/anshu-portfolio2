# Anshu Kumar Sharma — React Portfolio v2

Vercel-ready React + Vite portfolio foundation.

## Local run

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Vercel

Import the GitHub repository into Vercel. Framework should be detected as Vite.

- Install Command: `npm install`
- Build Command: `npm run build`
- Output Directory: `dist`

`vercel.json` is included for SPA routing.

## Before final launch

Replace the profile photo placeholder and social placeholder URLs, add the real CV PDF, certificate images, project screenshots, and any final project links.
